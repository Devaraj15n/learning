# Docker



### Docker Engine
1. Core service that runs containers

    it includes
    - Docker deamon
    - Docker CLI
    - REST API

2. Docker Image

    Blueprint/template used to create the container

        Node js app image
        Mysql image
        ubuntu Image

     Image is 

        Reusable
        Read only.
        Versioned.
    
3. Docker Container

    A running instance of an image

        you can :
            - Start
            - Stop
            - Delete
            - Restart
