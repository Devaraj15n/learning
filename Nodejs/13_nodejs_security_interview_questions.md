- use Https.
- Secure JWT scret key.
- Headers security.
- Prevent Sql injection.

- Configrue CORS.
- Implement Rate Limiting

### What is rate Limiting:
- RateLimit restricts the number of request is only allowed at certain time.



```javascript
const ratelimit=require('express-rate-limit');

const limiter=rateLimit({
    windowMs:15 *60 *1000,
    max:100
})
app.use('/api',limiter);
```

### what is XSS:
- XSS stands for Cross Site Scripting.
- Attackers attacks using the scripts.

### CSRF:
- Cross site Request forgery.
- User form website sending unwanted request to a website.

prevention:
- CSRF token(A CSRF token is a secret, unpredictable value generated by your server.)
- Allowed origin()
- Samesite cookie settings.

```javascript
res.cookie("token", jwtToken, {
    httpOnly: true,
    secure: true,
    sameSite: "strict"
});
```
### Diff between xss and CSRF:
| XSS | CSRF|
| ---- | ---- |

Script injetion | tricks the browser to make the request to another website
ORM and field validation | CSRF and Same site restriction

### SQL injection Prevention:
- use the Parameterized inputs instead of user input sql Statements.

### Why not JWT stored in Source code:
- if it exposed to attackers,they can able to create the tokens and use the application.
- use in Environment Variables or secret Manager variables.
